# MHW 武器 MOD 工具 v1.5.0

> by **真夜中のloop** · [B站主页](https://space.bilibili.com/478832252?spm_id_from=333.1007.0.0) · 2026-10-24

把武器 MOD 在**通用特效**和**独立特效**之间互转，或者把 MOD 的替换目标换成另一把武器。

不需要 Blender，独立 exe，双击就能用。

---

## 概念

### 通用特效 vs 独立特效

MHW 的武器特效挂在一个编号上，写在 `evwp` 文件的 `mEpvNo` 字段里：

| mEpvNo | 特效文件                          | 含义                     |
| ------ | ----------------------------- | ---------------------- |
| `0`    | `wp/<武器>/epv/hm_wpXX.epv3`    | **通用特效**：这类武器全部共用这一个特效 |
| `N`    | `wp/<武器>/epv/hm_wpXX_NN.epv3` | **独立特效**：只有这个编号的武器用它   |

`XX` 是武器类型代号：

| 代号        | 武器  | 代号           | 武器  |
| --------- | --- | ------------ | --- |
| `hm_wp00` | 大剑  | `hm_wp08`    | 斩斧  |
| `hm_wp01` | 片手剑 | `hm_wp09`    | 盾斧  |
| `hm_wp02` | 双剑  | `hm_wp10`    | 操虫棍 |
| `hm_wp03` | 太刀  | `hm_wp11`    | 弓   |
| `hm_wp04` | 大锤  | `hm_wbc`     | 重弩炮 |
| `hm_wp05` | 狩猎笛 | `hm_wbl`     | 轻弩炮 |
| `hm_wp06` | 长枪  | `hm_wp10mus` | 猎虫  |
| `hm_wp07` | 铳枪  |              |     |

音效控制表 `.epvsp` 在 `wp/<武器>/sound/` 下，命名规则相同。

### 编号的补零规则

- `1` → `hm_wp03_01.epv3`（两位补零）
- `28` → `hm_wp03_28.epv3`
- `111` → `hm_wp03_111.epv3`（三位不补）

## 五个功能

### 1. 通用特效 → 独立特效

```
mEpvNo        0  →  N
epv3          hm_wp03.epv3        →  hm_wp03_NN.epv3
epvsp         hm_wp03.epvsp       →  hm_wp03_NN.epvsp
wwct          hm_wp03_epvsp_snd_ct.wwct → hm_wp03_NN_epvsp_snd_ct.wwct
```

包里缺哪个文件，就从内置的游戏默认资源补一份，再改名。

### 2. 独立特效 → 通用特效

```
mEpvNo        N  →  0
epv3          hm_wp03_NN.epv3  →  hm_wp03.epv3
epvsp         hm_wp03_NN.epvsp →  hm_wp03.epvsp
wwct          hm_wp03_NN_epvsp_snd_ct.wwct → hm_wp03_epvsp_snd_ct.wwct
```

两个方向都保证包里有「跟当前形态对应」的 epvsp。

**默认路径会自动隔离**：如果 MOD 直接覆盖了 `vfx/efx/wp/wp03/` 下的 efx，
转独立特效时会把整个目录搬到 `vfx/efx/wp/wp03/_028/`（id=28），并同步改掉 epv3 里的路径引用。
不隔离的话，所有用通用特效的武器都会读到这份被改的特效。

**纯特效包也能转**：有些 MOD 只带 `wp/<武器>/epv/` 和 `sound/`，没有模型目录。
这种包转独立特效时会弹窗问你「这套特效属于哪把武器」——
因为补 evwp 必须知道 `wp/<武器>/<编号>/mod/` 是哪个目录。
选完之后工具会用内置的该武器 evwp 补进去，把 `mEpvNo` 设成新 ID。

> **epvsp 不是可选项**：独立特效缺了它，游戏会**卡在加载界面**（不是单纯没音效）。
>
> 所以转独立特效时如果包里没有、内置资源里也没有，工具会直接中止并报错，
>
> 不会生成一个进不去的包。

### 3. 替换武器模型

把「这个 MOD 替换的是 swo028」改成「替换 swo032」：

| 会改                                | 不会改                              |
| --------------------------------- | -------------------------------- |
| `mod3`（模型）                        | `tex`（贴图）—— **名字不改，也不跟着搬，留在原目录** |
| `mrl3`（材质）                        | `mdf2` / `efx` 等特效资源             |
| `ctc`（物理）                         | `Config.ini` 等配置                 |
| `evwp`（纳刀参数）                      |                                  |
| 随刀特效 `wp/<武器>/<编号>/epv/<编号>.epv3` |                                  |
| 部件模型 `wp/<武器>/parts/op_<编号>/`     |                                  |
| **独立特效的 epvid**（见下）               |                                  |

目标武器的目录名直接查数据表里的「主模型地址」，所以组合模型（`bs_swo001`）和独立模型（`swo028`）都能正确互转。

> **epvid 会跟着目标武器编号走**：如果这个包用的是独立特效，
>
> 替换成 swo032 时会把 `mEpvNo` 和 epv3 / epvsp / wwct 的名字一起从 `_28` 改成 `_32`。
>
> 独立特效的 id 惯例就是武器编号，不跟着改会和目标武器原本的特效撞车。

### 4. 只保留特效（删掉模型）

MOD 同时改了武器模型和特效，但你只想要特效时用这个：

| 删掉                              | 保留                        |
| ------------------------------- | ------------------------- |
| `mod3` / `mrl3` / `ctc` / `tex` | `evwp`（决定 mEpvNo，必需）      |
| `parts/op_xxx` 部件模型             | `epv3` / `epvsp` / `wwct` |
| `snd_xxx_bk.wwbk` 武器音效          | 随刀特效 `wp/<武器>/<编号>/epv/`  |
| `Config.ini` 等配置                | **整个 `vfx/` 特效资源**        |

> `vfx/` 目录里的 `mod3` / `mrl3` / `tex` 是**特效模型**，不会被删 ——
>
> 只清 `wp/` 下面的。实测一个 11 MB 的包清完剩 2 MB。

### 5. 删武器特效（保留随刀特效）

MOD 自带的武器特效你不想要、但模型自带的随刀特效要留着时用这个。
有两种力度，选中这一项后下面可以切换：

**保险（默认）** —— 只删默认路径，最不容易出事：

| 删掉 | 保留 |
|---|---|
| `wp/<武器>/epv/*.epv3` 武器特效 | `wp/<武器>/<编号>/` 整个随刀目录 |
| `wp/<武器>/sound/*.epvsp`、`*.wwct` | 武器模型（mod3 / mrl3 / ctc / tex 全不动） |
| `vfx/efx/wp/wpNN/` 整个目录 | **自定义路径的所有资源**（`vfx/huazha/`、`wp/ham/HEIPAI/` 等） |
| | 别的武器组 `vfx/efx/wp/wp00/` |

**彻底** —— 在保险的基础上，再顺着 epv3 / efx 的引用，把自定义目录里的
特效资源（efx 及其引用的 mod3 / tex / uvs）也删掉。删之前会先算一份
「mrl3 引用的贴图」保护名单，模型贴图不会被动。

> **为什么要分两种**：作者经常把武器特效、随刀特效、甚至武器模型的贴图
> 塞进同一个目录。比如「黑派大锤」里 `wp/ham/HEIPAI/BM.tex` 是 `mrl3` 引用的
> 模型贴图，和二十多个 `efx` 躺在一起。
>
> 实测这个包：保险模式只删 1 个文件（留 29 个 efx）；彻底模式删 32 个，
> 同时保住 `BM.tex` 和 3 个模型贴图。拿不准就用保险。

同时把 `mEpvNo` 归零 —— 不然它还指着刚删掉的 `hm_wpXX_NN.epv3`，
游戏找不到文件会卡在加载界面。归零后游戏回落到本体自带的通用特效。

> 「随刀特效」是跟着武器模型走的 `wp/<武器>/<编号>/epv/<编号>.epv3`，
> 和按编号挂在武器上的通用/独立特效不是一回事。

> **贴图为什么不改也不搬**：`mrl3` 里是用完整路径引用贴图的，比如
>
> `wp\swo\swo028\mod\swo028_BML`。只要贴图还留在 `wp/swo/swo028/mod/`，
>
> 这个引用就一直有效 —— 哪怕模型已经搬去 `swo032` 了。
>
> 所以替换后会出现：`swo032/mod/` 放模型，`swo028/mod/` 只剩贴图。这是正常的。

## 内置资源

exe 里打包了游戏默认的：

- 967 个 `.evwp`（每种武器的每个编号）
- 29 个 `.epv3`
- 23 个 `.epvsp` + 20 个 `.wwct`

来源：`D:\mhwmod解包\evwp all\chunk\wp`。

用途：MOD 里没带 evwp / epv 时（说明它用的是游戏默认的），从这里取一份改好再放进包。

武器名称、模型目录来自 `怪物猎人世界数据表` Excel 的「武器」页（4356 条），已导出成 `data/weapons.json`。

## 用法

1. 双击 `MHW_WP_Tool.exe`
2. **① 选择 MOD 包**：选 zip 或文件夹（直接拖路径进输入框也行），点「识别」
3. 看识别结果确认武器和当前形态
4. **② 要做什么** —— 两组**可以同时勾**：
   - **特效类型**：不改 / 通用 → 独立（填特效 ID，默认等于武器编号）/ 独立 → 通用 / 删武器特效（保留随刀特效）
   - **武器模型**：保持原样 / 替换成某把武器（点「搜索」按名字找）/ 只保留特效（删掉模型）
5. 先点 **「预览变更（不保存）」** 看日志确认要改哪些文件
6. 满意后点 **「执行」** 输出新 zip

> 两组一起做时会**先转特效、再动模型**。顺序不能反：转特效要改 evwp 里的
>
> `mEpvNo`，而换模型会把整个目录搬走。

- 勾「直接覆盖原包」会先存一份 `.bak` 再写回原位置
- 不勾的话输出到原包同目录，**文件名会带上转换结果**：
  | 操作                     | 输出名                  |
  | ---------------------- | -------------------- |
  | 通用 → 独立（ID 28）         | `原包名_独立特效28.zip`     |
  | 独立 → 通用                | `原包名_通用特效.zip`       |
  | 替换成 swo032（吼虎刀）        | `原包名_替换吼虎刀.zip`      |
  | 只保留特效 | `原包名_仅特效.zip` |
  | 删武器特效 | `原包名_仅随刀特效.zip` |
  | 特效 + 替换一起做 | `原包名_通用特效_替换吼虎刀.zip` |

  重复转换不会叠加后缀（会自动去掉上一次的）。
- 也可以命令行直接打开：`MHW_WP_Tool.exe --open "D:\path\mod.zip"`

```bash
# 生成内置资源（解包目录有更新时重跑）

python tools/test_strip.py
python tools/test_strip_wp.py

build.bat
```

## 已知限制

- 替换武器模型时，`sound/snd_<编号>_bk.wwbk`（武器音效）会跟着目录走并改名，但游戏里是否生效没实测。
- 只支持同一武器类型内部替换（太刀换太刀），跨类型没做。
- 轻弩炮（`lbg`）本身没有武器特效资源，转独立特效时只会改 mEpvNo，不会生成 epv3/epvsp。
